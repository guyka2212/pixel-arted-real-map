PIXEL WORLD

A real-world map rendered as pixel art in the browser.
It uses your device location to show where you are with a retro pixel pin.

HOW TO VIEW IT
Open index.html in a browser, or serve this folder and open the shown address:
python3 -m http.server 8080

WHAT IS INSIDE
index.html  page structure
style.css   pixel art theme
script.js   map renderer and location

The map data belongs to OpenStreetMap contributors.
